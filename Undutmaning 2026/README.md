## Description

A CTF created as a joint effort between Sweden's intelligence organizations:
* Swedish Military Intelligence and Security Service (MUST)
* Swedish Security Services (SÄPO)
* National Defence Radio Establishment (FRA)

The CTF will consist of 24 challenges and will be open for 8 hours, between 12:00 and 20:00 local time. 

The CTF is not a first-blood competition but uses weight based scoring.

Categories: crypto, web, pwn, reverse, forensics, programming, misc

CTF information, challenge descriptions, etc. will be presented mainly in Swedish.
