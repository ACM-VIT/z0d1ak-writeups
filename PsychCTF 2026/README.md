## Description

Welcome to the first edition of PsychCTF! It is a jeopardy-style CTF organized by SAIC, IIT Mandi. This flagship event is part of our tech festival, Xpecto!

The CTF is focused towards beginners and moderate players with some challenges for hardcode players as well.

Timeline:
- Start Date: 12am (IST), 14 March 2026
- End Date: 12am (IST), 16 March 2026

Categories include OSINT, Cryptography, Web Exploitation, Forensics, and more. We are also introducing a special beginners category to allow new joinees to get a basic idea of the CTFs.

Rules:
- No maximum team size
- All information will be shared on the Discord
- Prizes are subject to change without notice.
- Admin decisions are final.
